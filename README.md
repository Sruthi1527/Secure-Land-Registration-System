# DB Connection – Java Web Application

## 📌 Project Description

DB Connection is a Java Web Application that demonstrates how to connect a Java application with a MySQL database using JDBC.

The application provides **User Registration and Login functionality**. User information is stored in a MySQL database, and registered users can log in using their username and password.

---

## 🚀 Features

- User Registration
- User Login
- MySQL Database Connection
- JDBC Connectivity
- JSP Pages
- Java Servlets
- Login Validation
- Session Management
- Database Insert and Select Operations

---

## 🛠️ Technologies Used
